# Code of Conduct

MovieTrack uses a simple contributor standard:

- Be respectful and direct.
- Keep discussion technical and actionable.
- Do not harass, threaten, or target people.
- Do not share private user data, tokens, credentials, or sensitive watch history.
- Assume maintainers may remove comments, issues, or pull requests that make the project unsafe or hostile.

Security issues should follow [SECURITY.md](SECURITY.md), not public issue threads.
